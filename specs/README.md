# specs/

Specs do not live here. Each non-trivial feature gets one file in [`docs/superpowers/specs/`](../docs/superpowers/specs/), named `<date>-<feature>-design.md`, capturing the **what** and **why** — not implementation detail. The spec is the source artifact; code is generated from it. Superseded specs move to `docs/superpowers/specs/archive/` with a pointer to their successor.

Write a spec before planning or building a feature (see [../docs/WORKFLOW.md](../docs/WORKFLOW.md)). Small contained edits skip this.
