# Program handoff — retired

This document was the entry point for the 2026 professionalization program: a
progress table across its seven work packages plus the context that had no other
home. It stopped being updated on 2026-06-12 and the work kept going without it,
so by the time anyone read it the progress table was fiction and the "read this
fully first" instruction cost a session more than it gave.

It is retired rather than refreshed. Nothing points a session at it any more.

- **Where the current work is tracked:** the active plan in
  [`plans/`](plans/), which carries its own scope, task list, gates and
  `## Handoff log`. A plan whose Definition of Done has shipped moves to
  [`plans/archive/`](plans/archive/), so what is left in `plans/` is the work
  still open.
- **How to start a session:** [`../../AGENTS.md`](../../AGENTS.md) routes to the
  doc that owns whatever you are about to touch, and
  [`../WORKFLOW.md`](../WORKFLOW.md) owns the loop, the gates and the escalation
  protocol.
- **Which role to adopt:** [`../ROLES.md`](../ROLES.md).
- **What the program decided:** the specs in [`specs/`](specs/) are the decision
  records and they stay. Its session-by-session narrative is in git history.
